# Contributing

Thank you for helping make private image tools better.

1. Discuss large changes in an issue before building them.
2. Use Node 20+ and run `npm ci && npm run verify`.
3. Prefer standard browser APIs and keep third-party scripts out of the runtime.
4. Do not introduce tracking, third-party uploads, dynamic evaluation, or unsafe HTML injection.
5. Include accessibility and responsive behavior in any UI change.
6. Add meaningful regression tests to `tests/` for changes to policies, ZIP formatting, and filename rules.
7. Explain browser compatibility and performance tradeoffs in your pull request.

Pull requests should be small, with screenshots if visuals change. Be respectful in reviews and issues.
